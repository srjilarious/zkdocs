Zkdocs is a document site generator in the style of mkdocs, but intended for zig projects.  I wanted a tool that could give me similar features like I'm used to with mkdocs with the mkdocs-material extension.

WARNING:  This tool has been almost entirely developed with AI and the code quality has not been reviewed (yet).  I've been using it as a black box to experiment with AI-based development and get something useful at the same time.  So don't expect the best SW architecture!

Zkdocs has its own documentation served here: https://srjilarious.github.io/zkdocs
